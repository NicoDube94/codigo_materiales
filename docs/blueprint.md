# **App Name**: MateriLog

## Core Features:

- Quick-Scan Dashboard: Mobile-first interface to view products and their nested materials in a condensed table format.
- Intelligent Label Parsing: Use an AI vision tool to automatically extract energy efficiency details and codes directly from photos of material labels.
- Linked Component Creator: Create and link new materials (codes, descriptions, and photos) directly to existing parent product codes.
- Visual Asset Manager: Capture and attach photos to specific material records with cloud storage support.
- Fast Catalog Filter: Instantly search products by code (e.g., 43716VM) or material identifier to find components in the field.
- Synchronized Cloud Database: Real-time storage for material data and relationships, ensuring all field data is persistent.

## Style Guidelines:

- The palette is based on 'Industrial Precision', opting for a dark scheme to reduce glare in warehouse environments. Primary color is a focused Electric Blue (#3D88D1) against a Deep Slate background (#161B1F).
- Accent color: A high-contrast Cyan (#44D8D8) used for interactive elements and AI status indicators.
- A font pairing featuring 'Space Grotesk' for technical headers and numerical product codes for a tech-driven feel, with 'Inter' for the legible body text.
- Functional, thin-stroke geometric icons to represent parts, cameras, and connectivity, maintaining an uncluttered UI.
- Optimized vertical layout for mobile, utilizing horizontally scrollable table rows or cards to handle high-density technical data.
- Brief, satisfying micro-interactions when AI identifies text on a label, providing immediate user feedback.
